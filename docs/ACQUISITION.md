# Public acquisition resources

The October 2026 acquisition pass adds DCG and DSCG average calculators, an tools hub, and four original worked-example guides. Amortization and VAN guides include local arithmetic tools. The result is 47 canonical public pages and 47 original 1200×630 social cards.

The homepage and features page load through PublicPresentation without importing the authenticated App or Firebase. Protected library routes and APIs retain their existing access checks. The public sample still contains a bounded reviewed lesson and ten questions.

Calculator values stay in component memory, are not persisted or sent to the server, and never enter sharing URLs. Sharing accepts only canonical indexable public paths and removes query strings and fragments. Grade calculations use the cited official schedules, handle exclusions and optional-language bonuses, and describe numerical simulations rather than award decisions.

Build with the patched local Node runtime before testing. `node --test tests/*.test.mjs` covers calculation boundaries, public entry dependency separation, metadata, social assets, and public-only sharing and IndexNow payloads. Verify desktop and phone layouts on the READY production deployment as well.

After a meaningful publication, `scripts/submit-indexnow.mjs` verifies the public ownership file and deployed manifest before submitting canonical public URLs. A 200 response confirms receipt, while 202 indicates validation is pending. Neither guarantees indexing, ranking, traffic, or subscriptions. This does not submit to Google. Do not resubmit unchanged pages repeatedly.

No paid AI generation, advertising purchases, unsolicited outreach, fake reviews, or student-data transmission is part of this pass. Existing runtime security checks remain enabled; a managed-runtime patch pending at the hosting provider must not be represented as fixed by this release.
